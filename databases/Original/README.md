# Original Grazioso Salvare Database Artifact

This folder contains the original version of the Grazioso Salvare animal-shelter dashboard developed in CS 340.

The project uses Python, MongoDB, and a Jupyter-based dashboard to support animal record management and rescue filtering.

## Original Project Files

- `CRUD_Python_Module.py`
- `ProjectTwoDashboard.ipynb`

## Purpose

The original artifact demonstrates database connectivity, CRUD operations, and dashboard functionality using MongoDB-backed animal-shelter data.

This version is included in the ePortfolio to provide a comparison point for the database enhancement completed in CS 499.

## Enhancement Comparison

The enhanced version improves this original artifact through stronger configuration management, query validation, safer update and delete behavior, database indexing, automated testing, and improved portability.

See the enhanced artifact for the completed CS 499 database improvements.
